# Shikho Learning Report - Guideline

Internal reference for Shikho's Customer Care team on the **Shikho Learning Report** — a monthly link sent to parents showing how their child did last month: overall score, each subject, weak chapters, how regular they were, and leaderboard position. No app or login — just a link.

> **Status:** feature in development, ahead of launch. This guide is a reference for how it works.

## View
Open **`index.html`** in any browser. It is self-contained — annotated screenshots and the 78-second walkthrough video are embedded.

## Files
- `index.html` — the guide, self-contained (share this one)
- `guide-source.html` — editable source (loads images/video from `assets/`)
- `assets/` — annotated screen references + walkthrough video
- `narration-script-bangla.txt` — Bangla narration script for the walkthrough (not yet voiced)
