01

Learning Report কী?

Learning Report হলো প্রতি মাসে অভিভাবকের কাছে পাঠানো একটা link, যেখানে গত মাসে তাদের সন্তান পড়াশোনায় কেমন করেছে — সার্বিক স্কোর, প্রতিটি বিষয়, দুর্বল chapter, কতটা নিয়মিত ছিল আর leaderboard-এ অবস্থান — সব সহজভাবে দেখা যাবে। App বা login লাগবে না, শুধু link-এ tap।

কাদের জন্য

Report অভিভাবকদের জন্য — paid, trial ও free, সব student-এর অভিভাবকই দেখতে পারবেন।

Paid guardian — Automatic SMS

Paid student-এর অভিভাবক প্রতি মাসের শুরুতে SMS-এ link পাবেন (গত মাসের report)। আলাদা করে চাইতে হবে না।

Trial / Free — আপনি পাঠাবেন

এদের automatic যাবে না। আপনি CRM lead থেকে WhatsApp-এ link পাঠাবেন, যেভাবে এখন পাঠান।

Link personal রাখুন

link-টা যার কাছে থাকবে সে-ই খুলতে পারবে। তাই শুধু ঐ সন্তানের guardian-কেই পাঠাবেন।

03

Call Scenarios

1

নতুন Paid Guardian-কে Report বোঝানো

Guardian প্রথমবার report দেখছেন।
লক্ষ্য: নিজে link খুলে score ও subjects দেখতে পারা
  1. সালাম দিয়ে পরিচয় দিন — "আপনার সন্তানের গত মাসের report নিয়ে কথা বলব"।
  2. WhatsApp/SMS-এ পাঠানো link-এ একবার tap করতে বলুন।
  3. প্রথমে রেজাল্ট screen-এর উপরে বড় overall score দেখান।
  4. একটু নিচে নামিয়ে প্রতিটি subject-এর ফল দেখান; লাল subject-এ tap করতে বলুন।
  5. helpline 16780 দিয়ে ধন্যবাদ জানিয়ে শেষ করুন।
বলতে পারেন এভাবে
"ওই বড় number-টাই গত মাসে আপনার সন্তানের overall score। সবুজ মানে ভালো করছে। একটু নিচে নামলে প্রতিটা subject-এর ফল পাবেন — কোনটায় একটু বেশি মনোযোগ দরকার, সেটাও বোঝা যাবে।"
সতর্কতা: পরের মাসে নির্দিষ্ট নম্বর বা rank-এর নিশ্চয়তা দেবেন না।
2

Trial / Free Guardian Report চাইছেন

এদের automatic SMS যায় না।
লক্ষ্য: CRM থেকে WhatsApp-এ link পাঠানো
  1. Guardian-এর lead CRM-এ খুলুন।
  2. WhatsApp option দিয়ে report-এর link পাঠান।
  3. আগেই বলে রাখুন — সন্তান নতুন হলে কিছু জায়গা এখনো খালি থাকতে পারে।
  4. Line-এ থেকে link খুলতে সাহায্য করুন (Scenario 1-এর ধাপ)।
বলতে পারেন এভাবে
"আপনাকে এখনই WhatsApp-এ report-এর link পাঠিয়ে দিচ্ছি। খুলে একসাথে দেখি, কোনো login লাগবে না।"
সতর্কতা: trial/free report-এ তথ্য কম থাকতে পারে — এটাকে সমস্যা হিসেবে না বলে স্বাভাবিক হিসেবে বলুন।
3

Score / Number বুঝছেন না

"এই স্কোরটা কীভাবে এলো?"
লক্ষ্য: সহজ ভাষায় আশ্বস্ত করা — formula না বানিয়ে
  1. রঙ দিয়ে বোঝান — সবুজ ভালো, হলুদ মোটামুটি, লাল-এ practice দরকার।
  2. বলুন এটা গত মাসের ক্লাস ও পরীক্ষার ফল মিলিয়ে হিসাব করা।
  3. screen-এর কীভাবে নির্ধারিত হয় বাটন দেখান — ওখানে বিস্তারিত আছে।
  4. আরও বিস্তারিত হিসাব চাইলে note নিয়ে team-কে জানান।
বলতে পারেন এভাবে
"এই স্কোরটা গত মাসে ক্লাস আর পরীক্ষায় কেমন করেছে, তা মিলিয়ে বের করা হয়। screen-এ ‘কীভাবে নির্ধারিত হয়’ লেখা জায়গায় চাপ দিলে আরও বিস্তারিত দেখতে পাবেন।"
সতর্কতা: নিজে থেকে কোনো হিসাবের নিয়ম বা শতাংশ বানিয়ে বলবেন না।
4

"তথ্য ভুল / অন্য Student দেখাচ্ছে"

Guardian ভুল data-র অভিযোগ করছেন।
লক্ষ্য: শান্ত থেকে যাচাই ও escalate
  1. দুঃখ প্রকাশ করুন, তাড়াহুড়ো করবেন না।
  2. সন্তানের নাম ও class মিলিয়ে নিন।
  3. নিজে থেকে কারণ ব্যাখ্যা করবেন না।
  4. lead যাচাই করে বিষয়টা team/Product-কে জানান।
  5. অন্য কারও তথ্য থাকলে guardian-এর privacy রক্ষা করুন।
বলতে পারেন এভাবে
"দুঃখিত, বিষয়টা আমি এখনই দেখছি। একটু আপনার সন্তানের নাম আর class বলবেন? মিলিয়ে নিয়ে ঠিক করে জানাচ্ছি।"
সতর্কতা: অনুমান করে কারণ বলবেন না।
5

Report পাননি / Link খুলছে না

"link পাইনি" বা "খুলছে না"।
লক্ষ্য: আবার পাঠিয়ে খুলতে সাহায্য করা
  1. number ঠিক আছে কিনা মিলিয়ে, আবার WhatsApp-এ link পাঠান।
  2. internet connection দেখে আবার tap করতে বলুন।
  3. তাও না হলে link-টা Chrome browser-এ খুলতে বলুন।
  4. এরপরও না হলে বিষয়টা team-কে জানান।
বলতে পারেন এভাবে
"কোনো সমস্যা নেই, আমি আবার পাঠিয়ে দিচ্ছি। একটু internet আছে কিনা দেখে link-এ চাপ দিন — না খুললে Chrome-এ খুলে দেখুন, হয়ে যাবে।"

Agent কী করবেনenrollment নতুন কিনা দেখুন; data নিয়ে সন্দেহ হলে team-কে জানান।
Guardianক্লাসের এই শতাংশ কীভাবে হিসাব হয়?
গত মাসে যতগুলো লাইভ ক্লাস নির্ধারিত ছিল, তার মধ্যে সন্তান কতগুলো করেছে — সেটার শতকরা।
Agent কী জানবেনএখন শুধু করা লাইভ ক্লাস গোনা হয়; পরে recording দেখাও যুক্ত হতে পারে (internal)।
Guardianপড়াশোনা-র ক্যালেন্ডারে রঙগুলো কী বোঝায়?
সবুজ = ঐ দিনের সব ক্লাস করেছে, মাঝারি রঙ = আংশিক করেছে, লাল = মিস করেছে।
Guardianঅন্য কেউ কি এই link খুলতে পারবে?
যার কাছে link থাকবে সে খুলতে পারবে, আলাদা password নেই। তাই link-টা নিজের কাছে রাখবেন।
Agent কী করবেনlink শুধু ঐ সন্তানের guardian-কেই পাঠান — privacy রক্ষা করুন।
GuardianApp-এর সাথে মিলছে না।
report গত মাসের একটা স্থির ছবি; app-এ live তথ্য থাকে, তাই অল্প পার্থক্য স্বাভাবিক।
Agent কী করবেনবড় গরমিল হলে উদাহরণসহ team-কে জানান।
GuardianRank কীভাবে হিসাব হয়?
একই program-এর অন্য student-দের স্কোরের তুলনায় সন্তানের অবস্থান — স্কোর বেশি হলে rank উপরে। লিডারবোর্ড-এ নিচে নিজের rank দেখা যায়।
Agent কী জানবেনতুলনা একই program/batch-এর student-দের মধ্যে, স্কুল আলাদা করে নয়।
Guardianএটা কি শুধু paid-দের জন্য?
Report সবাই দেখতে পারেন; paid guardian-রা automatic পান, আর আপনাকে আমি নিজে পাঠিয়ে দিতে পারি।
Agent কী করবেনtrial/free হলে CRM থেকে WhatsApp-এ link পাঠান।
Guardianসন্তানের ফল কীভাবে ভালো করব?
লাল subject/chapter-এ একটু বেশি practice করালে ভালো; report-এ ওই chapter-এর video-ও আছে।
Agent কী করবেনগঠনমূলকভাবে বলুন; নির্দিষ্ট নম্বর/rank-এর নিশ্চয়তা দেবেন না।
